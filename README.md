## 🛠️ Tech Stack & Features

- **Framework:** [Next.js](https://nextjs.org/) (App Router) + React 19 + TypeScript
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Motion.dev](https://motion.dev/) (Framer Motion)
- **Interactive Shaders:** 
  - `@23rd/ascii-fluid` (WebGL ASCII Fluid Simulation)
  - Three.js `<ASCIIText />` Shader Footer
- **Design Engineer Mode:** Interactive video showcase mode with hover play/pause and custom cursor badges

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Rachit315/Portfolioo.git

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
